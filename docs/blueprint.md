# **App Name**: 7S Analyzer

## Core Features:

- Data Input: Users can input information into text areas, with each text area corresponding to one of the seven elements of the McKinsey 7-S framework.
- AI Analysis Generation: After filling in the text areas, the user can submit the information to a generative AI tool. The tool assesses the alignment between the seven elements and provides recommendations.
- Analysis Display: Generated analysis will be shown to the user as markdown in a separate display box on the page.
- Version Control and Historical Analysis: Allow users to save multiple snapshots or versions of their 7S analysis over time. Each save could be timestamped and optionally named (e.g., "Q1 2024 Analysis," "Post-Merger Alignment").
- Goal Setting and Action Item Tracking: Integrate a section where users can define specific, measurable, achievable, relevant, and time-bound (SMART) goals based on the AI analysis recommendations. For each goal, users could create actionable tasks, assign responsibilities, and set deadlines.
- Collaborative Features: Implement functionality to share an analysis with other team members (e.g., via a unique link or email invitation) and allow for collaborative editing and commenting. Different access levels (read-only, editor) could be supported.
- Enhanced Reporting and Export Options: Provide more sophisticated export options beyond basic HTML. This could include generating professional-looking PDF reports with charts, detailed markdown files, or even CSV exports of raw data. Users could customize which sections to include.
- Interactive Visualizations: Develop dynamic visualizations, such as radar charts or bar graphs, that represent the "strength" or "alignment" of each of the 7S elements based on user input or AI assessment. These could also show changes over time.
- Pre-built Templates and Industry Examples: Offer a library of pre-filled 7S examples for various industries (e.g., "Tech Startup," "Traditional Manufacturing," "Non-Profit") or common scenarios (e.g., "Pre-Merger Assessment").
- Contextual Guidance and Best Practices: Integrate small info icons or tooltips next to each 7S element that, when clicked or hovered, provide more detailed explanations, common pitfalls, and best practices for that specific 'S'.
- AI Feedback Loop and Refinement: Allow users to provide feedback on the AI-generated analysis (e.g., "helpful," "needs improvement," or specific suggestions). This data could be used to fine-tune the AI model over time.

## Style Guidelines:

- Primary color: Slate blue (#7395AE) to convey stability and strategic thinking.
- Background color: Off-white (#F1E9DA), to allow for a calm user experience.
- Accent color: Warm beige (#A18A68), used sparingly to call attention to actionable elements such as buttons.
- Body and headline font: 'Inter' (sans-serif), to convey neutrality and objectivity.
- Use simple, professional icons relevant to strategy and management concepts.
- Divide the page into clearly defined sections, one section for each of the seven elements of the McKinsey 7-S framework.
- Subtle loading animations to indicate AI processing without being distracting.
